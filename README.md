Pestañas 🚀

Gestor avanzado de navegación recurrente con automatización de apertura de pestañas, feedback visual y sonoro.

✨ Características

🕒 Programación Flexible: Define intervalos en minutos para cualquier URL.

🌓 Modo Oscuro: Interfaz adaptable para reducir la fatiga visual.

🔔 Alertas Inteligentes: Notificación visual (parpadeo verde), sonora (beep) y háptica (vibración).

📂 Importación/Exportación: Gestiona tus tareas masivamente mediante archivos CSV.

💾 Persistencia: Configuración guardada localmente en el navegador.

🚀 Instalación y Uso

No requiere instalación. Puedes ejecutarlo de dos formas:

Online: Accediendo a la URL de GitHub Pages.

Local: Descargando el archivo index.html y abriéndolo en cualquier navegador moderno.

🛠️ Tecnologías

HTML5 / JavaScript (Vanilla)

Tailwind CSS (Diseño responsivo)

Web Audio API & Vibration API
